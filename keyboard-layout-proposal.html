Existing ZMK capabilities kept in the proposal

Base keys

Typing positions, Shift, Tab, plain Escape, Backspace, Enter and Space remain. Caps becomes Control on the BT60, matching your MacBook. Fn + Tab supplies FR-OSS ²/³/¹ without consuming Escape.

Raise access

Current BT60: hold Caps or right Fn. Proposed BT60: hold far-left Fn or right Fn. MacBook: hold its built-in Fn for the same everyday actions.

Function and editing keys

On both: Fn + number-row positions gives F1–F12; Fn + Escape gives Grave; Fn + Tab gives ²; Fn + Backspace gives Delete. Insert, Home, End, Page Up and Page Down stay on Raise. The MacBook's own function row stays available.

Media and system keys

On both: Fn + Y/U/I gives Mute/Vol−/Vol+; Fn + Z/X/C gives Previous/Play/Next. Print Screen, Scroll Lock and context menu remain at the BT60's existing Raise positions. On macOS, some legacy keys depend on the app.

Adjust and maintenance

Hold Fn + the right Option position to enter Adjust. Fn + right Option + R enters the bootloader; the same chord + the ISO key beside left Shift resets the keyboard.

Bluetooth and power

Adjust keeps profile selections 1–5 and Bluetooth clear. They remain inactive because CONFIG_ZMK_BLE=n. USB use, sleep, and the one-hour idle sleep timeout stay as configured.

Optional ideas to try later

These are separate experiments, not part of the comparison above. I would try them one at a time and mirror any habit on the MacBook.

1. Tap Fn for one Raise key; hold it for repeated use

This reduces strain for an occasional F key or Delete: tap Fn, then tap the target key. A custom ZMK hold-tap could pair a momentary Raise with a sticky Raise. The MacBook would need a matching rule before this becomes a shared habit.

ZMK hold-tap · ZMK sticky layer

2. A one-key screenshot action

Fn + P currently sends Print Screen from the BT60, which macOS does not use like Windows. The same Fn + P position on both keyboards could instead trigger a macOS screenshot shortcut. This would change behavior, so it is separate from the core proposal.

3. Multi-tap for Caps Word

For identifiers such as CONFIG_ZMK_BLE, a double tap of a chosen key could start Caps Word. Choose a key you rarely double tap. Check support in pinned ZMK v0.3 and plan the Mac equivalent before adding it.
